Inside the first tool

What Batch Runner actually does.

Excel changes one input and shows you one answer. Batch Runner runs your whole scenario table through the model and lays every result out beside the assumptions that produced it. One press. Every row calculated, every result recorded, your model put back as it was.

01

Point at the inputs you want changed

On the control sheet, link to each cell in your model that Batch Runner should drive — type =, click the cell, press Enter. That is the whole setup. Nothing inside your model is edited or rebuilt.

Control sheet
Input 1='Model'!$C$5
Input 2='Model'!$C$8
Input 3='Model'!$C$12
… as many as you need · your model untouched
02

Point at the outputs you want read

The same way, link to the results you care about — IRR, margin, headroom, whatever your model produces. Every link is checked before anything runs, and a broken one is flagged with the reason rather than silently ignored.

Control sheet · link check
Output 1='Model'!$B$41YES
Output 2='Model'!$B$42YES
Output 3='Mdel'!$B$43NO — sheet
broken links are named, never skipped
03

Write your scenarios

One row per case, as many as you like. Fill in only the inputs that change from one scenario to the next — anything you leave blank simply keeps whatever your model already has.

Scenarios

04

Choose how the run works

Two options, and Goal Seek is entirely optional. Read the outputs. The model calculates on your inputs and the results are recorded. This is the normal mode.

Or solve for a target. Turn Goal Seek on, nominate one output as the target and one input as the variable to move, and give each scenario its own goal. Batch Runner works out what that input has to be, then records the outputs as usual.

05

Press run and read the table

Batch Runner works through the scenarios in turn, telling you which one it is on. Results land beside the inputs that produced them, so the finished block sorts, filters and charts like any other range. When the run ends, your model's original inputs are put back.

Straight answers

Does "pay once" really mean forever?+

Yes. One payment, and the tool is yours on any machine you own, for as long as you keep the file. There is no subscription, no licence to renew and no account that can expire. If a future version is a genuinely new product, it will be priced as one — and the version you bought will keep working regardless.

Will it work with my model?+

Batch Runner attaches to any model by pointing at cells you choose — you link inputs and outputs with ordinary formulas, so nothing inside your model has to change. It does not care how your model is built, only which cells you want driven and which you want read. If you are unsure it fits your file, email hello@heurekatools.com before buying and you will get an honest answer.

Do my files leave my computer?+

No. Batch Runner runs inside Excel on your own machine, on your own data. Nothing is uploaded, nothing is sent anywhere, and there is no account to create.

What are the system requirements?+

Batch Runner needs desktop Excel on Windows (2016 or newer) and the file must stay macro-enabled (.xlsm). It is not supported on Excel for Mac, Excel on the web, or the mobile apps. If you work on a Mac, do not buy it yet — a version for Google Sheets is in build.

Can I use it at work, or for client projects?+

Yes. A single purchase covers one person, including commercial and client work. If several people at your company need it, there is a team licence — just get in touch.
