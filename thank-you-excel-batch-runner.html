Wire it to your own model

Start small — two or three inputs and a handful of scenario rows. Confirm the numbers look right, then expand. It is far easier to spot a mis-pointed link on a short run than a full sheet.

Two things to know before your first run

Keep the file macro-enabled. Excel will show a security bar the first time you open it — click Enable Content. If you ever save it as .xlsx, the tool is silently stripped out.

Save before every run. If anything goes wrong mid-run, close the file without saving and reopen it. You are then back exactly where you started — but only if you saved first.
